# Carnet de réglages

Petite appli web pour garder sous la main ses réglages de tir à l'arc classique : viseur par distance, band, tiller, clicker, nock sets, berger button, matériel et flèches.

Les réglages sont enregistrés dans le navigateur du téléphone (rien n'est envoyé sur un serveur). La rubrique **Sauvegarde** permet d'exporter un fichier `.json` et de le restaurer sur un autre appareil.

## Mise en ligne avec GitHub Pages

1. Déposer ces fichiers à la racine du dépôt.
2. Dans le dépôt : **Settings → Pages → Build and deployment → Deploy from a branch**, branche `main`, dossier `/ (root)`.
3. L'appli est disponible quelques minutes plus tard à l'adresse `https://<utilisateur>.github.io/<dépôt>/`.

## Sur le téléphone

Ouvrir l'adresse, puis « Ajouter à l'écran d'accueil » (Safari : bouton Partager ; Chrome : menu ⋮). L'appli s'ouvre alors en plein écran avec son icône.
